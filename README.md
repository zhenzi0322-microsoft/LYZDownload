# LYZDownload

下载管理器，支持 HTTP/HTTPS（含 m3u8 视频流）与 BitTorrent（磁力链接 / .torrent 种子）下载，带任务管理、自动/自定义分类、系统通知与剪贴板监控。

## 功能特性

**多协议下载**
- **HTTP / HTTPS**：基于 `reqwest` 的 `Range` 分片多线程并发下载，支持断点续传、代理、限速、分片进度可视化。
- **m3u8 / HLS 视频流**：并发拉取 `.ts` 分片并按需 `AES-128-CBC` 解密（纯 `Rust` 零依赖实现），合并为单个视频文件。
- **BitTorrent**：磁力链接与 `.torrent` 文件均可，自带 `DHT / PEX`；会话级懒加载，暂停/继续复用同一 `torrent`句柄，删除可连同文件一并清除。

**任务管理**

- 任务详情抽屉（源/类型/进度/速度/剩余时间/已连节点/保存位置等）。
- 搜索框 + 手动排序（按名称、大小、进度、添加时间等）。
- 多选 + 批量操作（开始/暂停/删除/重试）。
- 全部暂停 / 全部恢复 / 清除已完成。
- 失败任务单任务「重试」，并支持「一键重试所有失败任务」
- 卡片与详情抽屉快捷操作：复制链接、打开文件夹、重新下载。
